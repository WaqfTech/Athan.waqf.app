# Athan Earth Benchmark Directory

This directory contains empirical benchmark suites, verification scripts, and technical
evaluations comparing Athan Earth against external calculation engines and API providers.

## Contents

- [accuracy-100-locations/](accuracy-100-locations/README.md):
  Empirical multi-provider accuracy test across 100 global coordinates (25% main cities,
  25% known cities, 50% random hard locations). Compares Athan Earth against Batoul Apps Adhan
  and the AlAdhan REST API. Includes raw CSV results and reproducibility steps.

- [athan-api-comparison.md](athan-api-comparison.md):
  Architectural and mathematical comparison of prayer time providers, including Batoul Apps
  Adhan, AlAdhan REST API, official observatories (USNO, NOAA), national authorities (Diyanet,
  JAKIM, Umm Al-Qura), and Kalimat Open Prayer Times.
