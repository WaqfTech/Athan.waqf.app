# أذان الأرض (athan.waqf.app)

[English](README.md) | العربية

أذان الأرض هو مرصد كوكبي تفاعلي ثلاثي الأبعاد.
يُحاكي المرصد كوكب الأرض في الفضاء مع إضاءة شمسية فلكية دقيقة،
وجبهات متحركة لمواقيت الصلاة، وتتبع استمرارية الأذان عالمياً عبر 15,000 تجمع سكاني.

## الميزات الرئيسة

- حساب فلكي دقيق لموقع الشمس وحركة الإضاءة والظل وفق خوارزميات NOAA وميوس (Meeus).
- خمس جبهات صلاة ديناميكية: الفجر، والظهر، والعصر، والمغرب، والعشاء.
- مراعاة اتجاهية حركة الشمس: شروق الصباح عند الارتفاع الصاعد، وغروب المساء عند الهابط.
- حساب صلاة العصر في الفرع المسائي مع اشتراط ثبوت ظل زوال حقيقي موجب.
- تتبع جبهة العشاء ذات الفاصل الزمني المعتمد للتقاويم المحددة (مثل 90 دقيقة لأم القرى).
- تمييز هندسي وفلكي بين خط الشفق الهندسي (0.0 درجة) والخط البصري الظاهري (-0.833 درجة).
- تظليل إشعاعي واقعي لسطح الأرض يراعي الحجب الكوكبي ويمنع تسرب الضوء للجانب الليلي.
- نموذج غلاف جوي منضبط يُحاكي تشتت الشفق مع انقطاع تام عند نهاية الشفق الفلكي (-18 درجة).
- حل معادلات العبور الشمسي بخوارزمية برنت (Brent) مع تصنيف حالات الغياب والتماس القطبي.
- نوافذ زمنية ممتدة عبر الأيام المدنية والمناطق الزمنية دون اختصار بزيادة 24 ساعة رقمية.
- إحصاءات استمرارية الأذان بخوارزمية مسح الخطوط (Sweep-line) لحساب التزامن الفعلي بدقة.
- لوحة فحص تفاعلية تُبيّن سند الحساب والعد التنازلي وتفاصيل كل ميقات.
- دعم 10 تقاويم معتمدة، ومذهبين فقهيين، و3 قواعد لتعديل الأوقات في خطوط العرض العليا.
- معمارية عميل ثابتة بالكامل تعمل على Cloudflare Workers دون حاجة لخوادم خلفية.

## أوجه التمايز في حساباتنا

تعتمد أغلب تطبيقات حساب المواقيت ومحاكيات الكرة الأرضية على افتراضات مبسطة
تؤدي إلى نتائج غير صحيحة عند الأطراف الجغرافية والزمنية. يُعالج أذان الأرض هذه
المسائل بالتزام الدقة الفيزيائية والمنهجية الفقهية:

1. إثبات الغياب الفلكي بدلاً من تلفيق المواعيد:
تلجأ المحركات التقليدية إلى حصر قيم الدوال المثلثية قسراً، أو تعيد وقت الزوال أو منتصف
الليل عند تعذر عبور الشمس للزوايا المطلوبة. يُنتج ذلك مواعيد وهمية للشروق أو المغرب في
فترات الليل القطبي وشمس منتصف الليل. يُثبت أذان الأرض الغياب الفلكي كقيمة صريحة ذات نمط
مستقل (ليل قطبي، شمس منتصف الليل، تماس أفقي). فعندما لا تشرق الشمس، لا يُصدر النظام
وقتاً مصطنعاً.

2. اشتراط وجود ظل زوال موجب لصلاة العصر:
تعتمد البرمجيات الشائعة صيغة الظل: tan(|phi - delta|). في شتاء المناطق القطبية تكون هذه
القيمة سالبة، مما يُنتج أوقاتاً وهمية تحت الأفق أو يفرض انزياحاً تلقائياً (مثل الظهر + ساعتين).
يشترط أذان الأرض ارتفاعاً شمسياً موجباً عند الزوال، ويُثبت تعذر الحساب الطبيعي متى ما تعذر
تشكل ظل زوال حقيقي.

3. دقة اتجاهية الجبهات والحركة الهندسية:
تعكس بعض المحاكيات مسار خطوط الصلاة أو تضع العصر في جانب الصباح. يحسب أذان الأرض
زاوية الساعة المحلية بدقة: جبهات الصباح (الفجر والشروق) تتقدم مع الارتفاع الشمسي
الصاعد، وجبهات المساء (المغرب والعشاء) تتقدم مع الارتفاع الشمسي الهابط، ويبقى العصر
محكوماً بالجانب المسائي بعد الزوال.

4. فصل الإضاءة الإشعاعية وإدارة الألوان:
تستخدم محاكيات الويب مظللات تجعل ضوء النهار يتسرب إلى الجانب المظلم من الأرض. يفصل
أذان الأرض ضوء الشمس المباشر عن تشتت الغلاف الجوي وإضاءة المدن، ويعتمد على المتجهات
الهندسية الكروية لحجب الضوء كلياً في الجانب الليلي، مع تطبيق إدارة ألوان منضبطة
(Three.js tone mapping و sRGB).

5. حساب استمرارية الأذان بحساب الفترات المتقاطعة:
بدلاً من التقسيم التقريبي إلى فئات زمنية ثابتة تُشوه أعداد التزامن، يعتمد أذان الأرض
خوارزمية مسح الخطوط المستقيمة (Sweep-line) عبر نهايات الفترات، لحساب التزامن الفعلي
للأذان عبر 15,000 تجمع سكاني بدقة رياضية متكاملة.

## منهجية الإنجاز والتحقيق

تحقق هذا الانضباط الفلكي والبرمجي عبر منهجية بحثية دقيقة ومتدرجة:

1. وثيقة العمل البحثي (R0001):
صيغت متطلبات المعالجة في وثيقة مواصفات هندسية تضمنت 13 عيباً محققاً، و8 شواهد خطأ
مرجعية، و12 وحدة تنفيذية، و30 معيار قبول واضح (مفصلة في المسألة رقم 5 ومجلد الأدلة).

2. هندسة البرمجيات بالفرق المتعددة (Teamwork):
نُفذ العمل عبر منظومة وكلاء ذكاء اصطناعي موزعة ومختصة: وكلاء استكشاف الخصائص،
ووكلاء كتابة الخوارزميات، ووكلاء مراجعة الجودة، ووكلاء اختبار الخصومة.

3. منظومة اختبارات تنافسية من خمس طبقات:
بُنيت حزمة اختبارات شاملة تضم 761 اختباراً آلياً عبر 35 ملف اختبار، شملت الحالات
الحدية في ترومسو، وتماثل انخفاض الشمس، وضغط التزامن على المعالجات، وتعمل بنجاح تام.

4. التدقيق المستقل للإنجاز (Victory Audit):
خضعت التعديلات قبل اعتمادها لتدقيق برمجي مستقل تحقق من أصالة الخوارزميات،
وغياب الواجهات الصورية أو الحيل الالتفافية، وسلامة البناء والاختبارات بنسبة 100%.

5. توثيق رياضي وفلكي مفتوح:
نُشرت جميع الأطر المرجعية والمعادلات الفلكية وخوارزميات برنت في وثيقة
docs/solar-model.md لإتاحة التحقق العلمي والتطوير المفتوح للجميع.

## النماذج الرياضية والفيزيائية

موقع الشمس:
حساب القرون اليولية بالنسبة لحقبة J2000.0، ومتوسط الشذوذ الشمسي، ومعادلة المركز،
والطول الظاهري المصحح للترنح والزيغ. استخراج الميل الكلي المصحح، وميل الشمس،
ومعادلة الوقت. تحديد النقطة تحت الشمس باعتماد ميل الشمس كخط عرض ومقلوب زاوية غرينتش كخط طول.

حل جذور الأحداث الشمسية:
تحديد لحظات عبور الارتفاع الشمسي عبر خوارزمية برنت (Brent) مع التمييز بين:
- العبور: لحظة محددة بدقة تحت الثانية.
- الليل القطبي (alwaysBelow): بقاء الشمس دون الارتفاع المطلوب طوال اليوم.
- شمس منتصف الليل (alwaysAbove): بقاء الشمس فوق الارتفاع المطلوب طوال اليوم.
- التماس (Grazing): ملامسة الأفق عند الزوال أو النظير دون اجتياز.
- التحقق من ظل الزوال: اشتراط ارتفاع شمسي موجب لصلاة العصر.

هندسة جبهات الصلاة:
حساب زاوية الساعة المحلية H = wrap180(longitude - subsolarLongitude):
- الفجر والشروق: فرع الصباح الصاعد (H < 0).
- المغرب والعشاء: فرع المساء الهابط (H > 0).
- الظهر: قوس زوال الشمس في النصف المضيء.
- العصر: مسار الظل المسائي (H > 0).
- المغرب: مسار الغروب الظاهري (-0.833 درجة).
- العشاء ذو الفاصل الثابت: مسار الغروب المزاح زمنياً بمقدار الفاصل.

## إفصاحات نموذج استمرارية الأذان

إشعار بشأن استمرارية الأذان (المعيار A26):
يُسجل أذان الأرض نسبة استمرارية تبلغ 100 بالمئة في ظل إعدادات المحاكاة المرجعية.
هذا الرقم هو خاصية رياضية مشروطة بما يلي:
1. قاعدة البيانات المعتمدة وتضم قرابة 15,000 تجمع سكاني.
2. التقويم الفلكي، والمذهب، وقاعدة العرض العالي المختارة.
3. افتراض مدة اسمية قدرها 4 دقائق للأذان في كل تجمع.

لا يُعد هذا الرقم دليلاً ميدانياً أو إثباتاً حسياً على رفع الأذان سماعاً بلا انقطاع في كل
بقعة جغرافية، إذ تخرج الممارسات المحلية والمناطق غير المأهولة عن نطاق النموذج الفلكي.

## تشغيل المشروع محلياً

المتطلبات:
- Node.js بإصدار 22 أو أحدث
- مدير الحزم aube أو aubr أو pnpm

تثبيت التبعيات:
```bash
aube install
# أو
pnpm install
```

تشغيل خادم التطوير:
```bash
aube dev
# أو
pnpm dev
```

تنفيذ الاختبارات:
```bash
aube test
# أو
pnpm test
```

فحص الأنواع وبناء حزمة الإنتاج:
```bash
aube build
# أو
pnpm build
```

النشر على Cloudflare:
```bash
aube run deploy:dry
# أو للنشر المباشر
aube run deploy
```
